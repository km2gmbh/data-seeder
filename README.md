# Data seeder for TYPO3

This extension provides a command, that allows seeding data from YAML files into a TYPO3 database. 
The seeds are designed to work without static UIDs 

## Motivation

Working in a team on a project presents multiple challenges.
One of these challenges is providing content data during development.
There are multiple approaches for this challenge. 
Our approach is to provide static data, that can grow during project progression and can be handled by VCS.
